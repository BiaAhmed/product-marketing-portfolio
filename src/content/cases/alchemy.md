## Context
Alchemy's documentation was rich but hard to find, slowing both self-serve adoption and sales cycles. The content team also struggled to ship updates quickly.

## What changed
- Re-architected the docs IA with clear canonical rules and schema markup for crawling.
- Built reusable templates and a publishing checklist to keep quality high while reducing cycle time.
- Migrated the library into Webflow CMS for better ownership across teams.

## Outcome
Search performance improved alongside developer satisfaction, with the new workflows keeping documentation fresh and discoverable.
